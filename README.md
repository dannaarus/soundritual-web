# Sound Ritual Web

Sitio estático bilingüe. No requiere instalación ni compilación.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `sound-ritual-web` en GitHub.
2. Descomprime el ZIP y sube **el contenido** de la carpeta (no la carpeta contenedora) a la raíz del repositorio, mediante Add file → Upload files. Confirma con Commit changes.
3. En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta / (root). Guarda.
4. GitHub mostrará la dirección `https://TU-USUARIO.github.io/sound-ritual-web/`.

## Vista local
Abre index.html con tu navegador. Mantén los archivos y carpetas juntos.

## Archivos
- index.html: contenido y estructura.
- styles.css: diseño adaptable.
- script-1.js: selector de idioma.
- script-2.js: ventanas de experiencias.
- assets/: fotografías y logo originales extraídos del HTML.
- .nojekyll: publicación estática directa (opcional).
